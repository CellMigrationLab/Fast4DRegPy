# Published movie: XY projections

Maximum-intensity projections over Z of frames 0, 6, 12, 18 and 24 of
`2.1.2-LargeDrift_original.tif` from the Fast4DReg synthetic large-drift
dataset ([Zenodo 7514913](https://zenodo.org/records/7514913)), full field of
view, otherwise unmodified.

`manifest.json` records the source, checksums and the published drift of
these frames (Fast4DReg paper, Fig. S1A). The generator leaves frame 0
unchanged, so the translation that corrects frame `t` is `-drift[t]`.

The dataset is published under CC BY 4.0.
